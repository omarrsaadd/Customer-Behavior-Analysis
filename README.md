# Customer-Behavior-Analysis
Customer behavior analysis using Python, Pandas, PostgreSQL, SQL, and Power BI to transform raw data into actionable insights through data cleaning, exploratory analysis, and interactive dashboards.

## Project Overview

This project focuses on analyzing customer purchasing behavior to identify trends, product preferences, discount usage, and customer satisfaction patterns. Using Python, PostgreSQL, SQL, and Power BI, the project transforms raw customer data into meaningful insights that support data-driven decision-making.

The analysis covers the complete data analytics workflow, from data preparation and database management to SQL-based analysis and interactive dashboard development.

## Objectives

- Analyze customer purchasing behavior and shopping preferences.
- Identify the most popular products and highest-rated items.
- Examine purchasing frequency and discount usage.
- Explore customer satisfaction through product review ratings.
- Develop an interactive dashboard to communicate key findings and performance indicators.

## Tools & Technologies

| Tool | 
| Python | Data preparation and processing |
| Pandas | Data manipulation and cleaning |
| PostgreSQL | Database storage and management |
| SQL | Data analysis, aggregation, and insight generation |
| Power BI | Interactive dashboards and data visualization |

## Project Workflow

### 1. Data Preparation and Cleaning
- Loaded and processed the dataset using Python and Pandas.
- Prepared the data for database storage and analysis.
- Reviewed data quality and addressed cleaning requirements where necessary.

### 2. Database Management
- Imported the prepared dataset into PostgreSQL.
- Used Python and Pandas to transfer the data into the database.
- Queried and explored the stored data using SQL.

### 3. Exploratory Data Analysis (EDA) with SQL
- Analyzed product ratings to identify highly rated products.
- Examined purchasing frequency and customer activity.
- Investigated discount usage across purchasing categories.
- Aggregated customer data to identify patterns and trends.

### 4. Power BI Dashboard
- Designed an interactive dashboard to present customer behavior insights.
- Used charts, KPIs, and visual elements to communicate key findings.
- Organized the dashboard to make customer purchasing patterns easier to understand.

## Key Analytical Questions

The project explores questions such as:

- Which products receive the highest average customer ratings?
- How does purchasing frequency vary across customers?
- How frequently are discounts used?
- What patterns can be identified in customer purchasing behavior?
- How can customer data support better business decisions?
